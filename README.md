## Stack

## Features
- Professional public website
- Student registration and session foundation
- Courses / modules / lessons data model
- Enrollments and progress tracking data model
- Quiz and certificate data model
- Admin/student role model
- SEO metadata, robots and sitemap

## Deployment
Create a PostgreSQL database, set `DATABASE_URL`, `JWT_SECRET`, and `NEXT_PUBLIC_SITE_URL`, then run `npm install`, `npx prisma db push`, and `npm run build`.

External account setup (domain, hosting, database, email and payment provider) must be completed in the owner's accounts. Never commit secrets to GitHub.
